# Промпты: миграция на Nuxt 4

Порядок запусков. Один запуск = один блок этапов из §11 `INSTRUCTION-NUXT4.md`.
Между блоками — `/clear`, иначе контекст забивается и качество падает.

Старт сессии:

```
cd d:\work\my_projects\mebel-shop
claude
/add-dir d:\work\my_projects\avto-landing
/add-dir d:\work\my_projects\rexas
```

Доноры подключать оба сразу: `avto-landing` нужен почти на каждом этапе,
`rexas` — с 4-го запуска.

```

код внутри файлов больше ничего не трогай. в конце покажи git status и дерево app/
```

Проверить самому: `app/` содержит 10 позиций из §3, `git status` показывает
переименования (`R`), а не удаление плюс добавление.

## Если что-то пошло не так

| Симптом | Куда смотреть |
| --- | --- |
| `Cannot find module '~~/interfaces/...'` | §3.1, замена алиасов не доехала до `server/` |
| `eslint.config.mjs` не находит `.nuxt/eslint.config.mjs` | не прошёл `nuxt prepare` — запустить руками |
| Фильтры каталога перестали обновляться | §7.2, `shallowRef` в `useAsyncData` |
| `nuxt generate` падает на пререндере | `nitro.prerender.ignore` в §6.7 |
| На Pages битые ассеты | `NUXT_APP_BASE_URL` не проброшен в сборку |
| Форма на Pages даёт 404 | форма не переведена на `useFormSubmit`, §9 |
