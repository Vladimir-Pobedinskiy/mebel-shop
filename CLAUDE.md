# mebel-shop

Демонстрационный интернет-магазин мебели на Nuxt 4. Собран и опубликован
на GitHub Pages: <https://vladimir-pobedinskiy.github.io/mebel-shop/>

**Перед работой прочитать `README.md`** — там стек, структура, устройство данных,
авторизация, режим статической витрины и список известных пробелов.

## Ключевое

- Клиентский код — в `app/` (srcDir Nuxt 4). `~` и `@` ведут в `app/`,
  `~~` и `@@` — в корень, поэтому интерфейсы импортируются как `~~/interfaces/...`.
- Данные — `db.json` + json-server (порт 3001), `BASE_URL="http://localhost:3001"`.
  `db.json` только дополнять, не переписывать целиком; отступ — два пробела,
  файл в `.prettierignore`.
- Сопоставление URL и данных — только `routes.json`. `routeRules` не использовать.
- POST-хендлеры в `server/api/` вычитывают тело, но не пробрасывают его в json-server:
  на singular-ресурсе тот перезапишет ключ-заглушку телом запроса.
- `auth.baseURL` — относительный `'/api/'`. С адресом json-server модуль
  `@sidebase/nuxt-auth` затирает заглушки `auth-login` и `auth-registration`.
- Формы отправляются через `useFormSubmit`: при `STATIC_DEMO=true` запрос не уходит,
  форма отдаёт заранее заданный ответ. Ломать этот механизм нельзя — на нём держится
  витрина на Pages.
- Каталог — два раздела, «Корпусная мебель» и «Кухни». Меню собирается из
  `catalog.categories`; при правке каталога проверять мегаменю, бургер, подвал
  и секции главной.
- Стиль кода: табы, без `;`, одинарные кавычки, printWidth 120.
  Комментарии и тексты интерфейса — на русском.
- `npm run lint` и `npx nuxt typecheck` обязательны перед коммитом.

## Команды

```bash
npm run double   # nuxt dev (3000) + json-server (3001)
npm run lint
npx nuxt typecheck
npm run build && npm run preview
```
